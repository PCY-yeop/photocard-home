==== 구글 시트로 현장 관리하기 ====

[처음 한 번만 설정]
1. 구글 시트(sheets.google.com)에서 새 스프레드시트를 만들어요.
2. 메뉴 파일 → 가져오기 → 업로드 → "시트양식.csv" 선택 → "현재 시트 바꾸기" → 데이터 가져오기
   (현재 3개 현장이 표로 들어가요)
3. 메뉴 파일 → 공유 → 웹에 게시
   - 왼쪽 "전체 문서"를 현장 목록이 있는 시트 이름으로 바꾸고
   - 오른쪽을 "쉼표로 구분된 값(.csv)"으로 바꾼 뒤 → 게시 → 나온 주소 복사
4. js/data.js 위쪽의  const SHEET_CSV_URL = "";  따옴표 사이에 복사한 주소를 붙여넣고 저장
5. Vercel에 다시 올리면 끝. 이후부터는 시트만 고치면 사이트가 바뀌어요.

[평소 사용법]
- 현장 추가  : 표 맨 아래 새 줄에 입력 (지역, 현장명, 홈페이지 3칸은 꼭 필요)
- 현장 수정  : 칸의 글자만 고치기
- 현장 삭제  : 줄 삭제
- 잠시 숨기기 : "숨김" 칸에 숨김 이라고 적기 (지우면 다시 보여요)
- 순서 변경  : 줄을 위/아래로 옮기기 (화면 순서와 같아요)
- 반영 시간  : 시트를 고친 뒤 보통 5분 안에 사이트에 반영돼요

[열 이름은 바꾸지 마세요]
지역 | 현장명 | 홈페이지 | 상태 | 주소 | 규모 | 타입 | 분양가 | 입주 | 전화 | 로고 | 이미지 | 숨김
- 지역   : 서울 / 인천 / 경기도 / 지방 중 하나 (data.js 의 REGIONS 이름과 같아야 해요)
- 상태   : 분양중 / 분양예정 / 마감임박 / 마감 (비워도 됨)
- 전화   : 현장 전용 번호 (비우면 대표번호 1800-6988 사용)
- 비워도 되는 칸은 비워두면 카드에서 그 줄이 자동으로 빠져요

[이미지 넣는 법]
방법 1) 사이트의 img 폴더에 파일을 넣고 → 시트에는 파일명만 적기 (예: visual-bg-01.jpg)
        (이 방법은 Vercel에 다시 올려야 해요)
방법 2) imgbb, Cloudinary 같은 곳에 올리고 → 나온 https://... 주소를 그대로 붙여넣기
        (Vercel에 다시 올릴 필요 없음)
- 두 방법을 한 시트에서 섞어 써도 돼요.
- 권장: 가로 1200px, 500KB 이하

[문제가 생기면]
- 시트가 안 불러와지면 data.js 의 SITES 목록이 대신 나와요 (사이트가 비지 않아요)
- 최근에 불러온 시트 내용은 방문자 폰에 저장돼서, 잠깐 접속이 불안정해도 마지막 내용이 보여요
- 바뀐 게 안 보이면: 시트에서 "웹에 게시"가 켜져 있는지, 주소를 정확히 붙여넣었는지 확인
