==== 수정 방법 ====
모든 수정은 js/data.js 한 파일에서 합니다. (index.html / css / app.js 는 건드릴 필요 없음)

[현장 수정]   SITES 안 블록의 값만 바꾸기 (샘플 4개는 실제 정보가 아니니 꼭 교체!)
[SAMPLE 표시] 내용을 고쳤으면 블록 안 sample: true, 줄을 지우세요
[이미지 교체] img/ 폴더에 넣고 cover: "img/파일명.jpg" 로 적기 (가로 1200 x 750 권장, 500KB 이하)
              샘플 이미지: img/sample-1.jpg ~ sample-4.jpg (같은 이름으로 덮어써도 됨)
[현장 추가]   블록 복사 → 붙여넣기 / 숨기기: hidden: true,
[전화·SNS·카카오톡 주소]  data.js 위쪽 SITE
[색상]        css/style.css 맨 위 :root 변수 (--navy, --blue, --purple, --gold)
